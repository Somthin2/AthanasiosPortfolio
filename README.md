# Athanasios Pavlides — Portfolio

Personal portfolio site for Athanasios Pavlides, cybersecurity analyst and security researcher based in Cyprus.

**Live:** [somthin2.github.io/AthanasiosPortfolio](https://somthin2.github.io/AthanasiosPortfolio/)

## Stack

- Vanilla JS — MVC architecture (Model / View / Controller), no frameworks
- CSS custom properties, CSS animations
- Persona 5 Royal-inspired brutalist UI — ransom-note typography, screen wipe transitions, P5R colour palette
- [FormSubmit](https://formsubmit.co) for the contact form and visitor notifications
- Hosted on GitHub Pages

## Features

- Animated boot sequence on load
- Keyboard-navigable menu (↑ ↓ Enter Esc)
- Skill bars, project cards pulled from a data model
- Contact form with spam honeypot
- Silent visitor ping — owner receives an email with IP, location, referrer, and timestamp on each unique visit
